# クレヨン牧場

クレヨンで描いたらくがきモンスターが3Dになって動き出す、お絵かき育成バトルゲームです。

## あそびかた

1. 18色のクレヨンでモンスターの「まえ」と「うしろ」を描く（からだから細くのばした線が、自動で うで・あし・つの になります）
2. 「そのまま／かわいく／かっこよく」の補正を選んで、牧場の仲間にする
3. 牧場で ごはん・とっくん・なでる・じしゅトレ（待っている間に強くなる）で育てる
4. 地図の丸をタッチして冒険へ。じゃんけんで勝った方が技を出せるバトルで、ケシゴムだいおうから色を取り戻す

## とくちょう

- Three.js による3D表示（描いた絵をふくらませて関節つきのモデルにします）
- じゃんけん式バトル、属性魔法、ひっさつわざのカットイン
- 5つのエリアとボス、ストーリー、エンディング後の「むげんの とう」
- BGM・効果音は Web Audio でその場で合成
- 会話や技名は端末の日本語読み上げ音声でフルボイス（声の質は端末によって変わります）
- 育成データはブラウザ（localStorage）に保存

## うごかしかた

`index.html` をブラウザで開くだけで遊べます。ビルドは不要です。
Three.js（r128）は cdnjs から読み込みます。
